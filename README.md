# ISP Panel

Portal técnico e estratégico multi-tenant para assessoria de provedores.

Implementação da Fase 1 em andamento: Django 5.2, PostgreSQL 17, interface server-side
e API versionada. Veja as decisões em [docs/adr](docs/adr).

O portal apresenta diagnóstico, riscos, capacidade e plano de evolução. Não
substitui NetBox, Zabbix, LibreNMS ou sistemas de gestão do ISP.
